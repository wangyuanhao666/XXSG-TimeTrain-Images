# 象限时光 · 时光列车插画库

这个仓库只存放时光列车的插画文件和公开图片清单，不存储应用账号或任务数据。

## 杭黄线与中国漫游

九站依次为：杭州东、富阳、桐庐、建德、千岛湖、三阳、绩溪北、歙县北、黄山北。`originals/` 保存生成的 PNG 原图，`scenes/` 保存供网页加载的 WebP 文件，`manifest.json` 记录站点与图片的对应关系。

中国漫游从杭州东再出发，随后依次经过另外 33 个省级地区的主题站。站点与文件名见 `grand-tour-stations.json`，全套缩略预览见 `contact-sheet.jpg`。

画风基准：暖色纸纹、水彩晕染、细线描边、柔和的鼠尾草绿和赭色。中国漫游插画以各地地标、风景和城市气质为主，不要求出现车站或列车；画面是旅行主题艺术创作，并非真实地理照片。图片由 Codex 内置生图工具制作，WebP 文件由 PNG 原图压缩转换而来。

网页从 GitHub Pages 获取 `manifest.json` 和图片。图片清单加载失败时，杭黄线显示应用随包提供的原有九张插画，中国漫游显示随包提供的通用沿途水彩画。

新增图片时，在对应站点数组中追加一条 `file` 和 `alt`，路径必须指向本仓库 `scenes/` 目录。请勿在已有文件名下直接替换图片；使用新的版本文件名，以避免浏览器缓存显示旧图。
